# 🗼 Тайник в старой башне

Консольная текстовая игра на Python. Один файл `quest.py`, без импортов и
сторонних библиотек: только `input`, `print`, `if/elif/else`, `while`, `break`.

## Запуск

```bash
python3 quest.py
```

На Windows:

```bash
python quest.py
```

## Управление

На каждом ходу игра спрашивает номер действия:

| Ввод | Действие |
|---|---|
| `1` | Идти дальше — переход в следующую комнату. В 4-й комнате это выход и победа |
| `2` | Обыскать комнату — один раз на комнату, даёт награду или урон |
| `3` | Выпить зелье — `+30` здоровья, потратив одно зелье |

Любой другой ввод (буквы, `9`, пустая строка) → сообщение «Я не понял тебя»
и тот же ход продолжается.

## Как устроен один ход

Порядок в коде строгий, от него зависит баланс:

1. `health = health - 5` — голод списывается **до** меню (строка 24).
2. Если `health <= 0` — `break`, игра заканчивается поражением (строки 25–26).
3. Если `health < 30` — печатается предупреждение (строки 28–29).
4. Печатается статус: комната, здоровье, золото, зелья (строки 31–34).
5. Печатается меню и читается `choice` (строки 36–40).
6. Срабатывает одна из веток: идти / обыскать / зелье / «не понял»
   (строки 42–93).

Важная деталь: голод уже списан до ввода, поэтому **неверный ввод тоже
стоит 5 здоровья**. Формально это «время идёт, пока герой думает».

## Переменные

| Переменная | Старт | Что делает |
|---|---:|---|
| `health` | 100 | Здоровье. Уменьшается от голода и ловушек, увеличивается зельем, потолок 100 |
| `gold` | 0 | Золото. Только растёт: награды за обыск и 100 за выход |
| `potions` | 1 | Зелья. Тратятся по одному, пополняются в 3-й комнате |
| `room` | 1 | Текущая комната, от 1 до `rooms_total` |
| `rooms_total` | 4 | Сколько всего комнат; меняет длину игры |
| `searched` | `False` | Обыскана ли текущая комната. Сбрасывается при переходе |
| `name` | ввод | Имя героя. Пустой ввод → «Безымянный» |

## Ветка «Идти дальше» (строки 42–50)

- Если `room == rooms_total` → `+100` золота и `break`. Это единственная победа.
- Иначе `room = room + 1`, а `searched = False`, чтобы новую комнату можно
  было обыскать.

Победа возможна только через эту ветку: выход из цикла по смерти всегда
означает поражение.

## Ветка «Обыскать» (строки 52–78)

Сначала проверяется флаг `searched`: повторный обыск ничего не даёт.
Потом — эффект по номеру комнаты:

| `room` | Эффект | Здоровье | Золото | Зелья |
|---|---|---:|---:|---:|
| 1 | Старый кошель | — | +20 | — |
| 2 | Растяжка со стрелой и тайник | −30 | +15 | — |
| 3 | Крыса и зелье в углу | −15 | — | +1 |
| 4 | Доспех-страж и сундук | −20 | +50 | — |

Максимум золота за один забег: 100 (выход) + 20 + 15 + 50 = **185**.

## Ветка «Зелье» (строки 80–90)

Три случая: зелий нет → отказ; здоровье уже 100 → «зелье пока не нужно»;
иначе `potions - 1`, `health + 30` и обрезка до 100. Зелье не тратится
впустую.

## Конец игры (строки 95–104)

После цикла проверяется `health > 0`:

- да → «ПОБЕДА!» и собранное золото;
- нет → «остался в башне навсегда» и собранное золото.

Смерть от ловушки в комнате фиксируется на следующей проверке `while`,
поэтому отдельного сообщения о смерти внутри ветки нет.

## Ограничения

- Один забег: после «ИГРА ЗАВЕРШЕНА» программа закрывается, перезапуск —
  заново.
- Нет сохранений, нет случайности: все события детерминированы.
- Комнаты не связаны сюжетом, эффекты заданы жёстко через `if room == ...`.
- Нет функций и структур данных: чтобы добавить пятую комнату, нужно
  дописать блок `elif room == 5`.
- В коде нет комментариев: структура видна только по именам переменных,
  отступам и тексту игры.
